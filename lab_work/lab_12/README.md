# Лабораторна робота № 12

**Тема:** З’єднання комп’ютерів у безпровідній мережі

## Виконано

- побудовано мережу з маршрутизатором WRT300N і двома ноутбуками;
- у ноутбуки встановлено безпровідні адаптери WPC300N;
- створено мережу `LAB12` на каналі 6;
- налаштовано захист WPA2 Personal з шифруванням AES;
- увімкнено автоматичне призначення адрес через DHCP;
- перевірено зв’язок між клієнтами та маршрутизатором;
- отримано 0 % втрат пакетів під час перевірки командою `ping`.

## Параметри мережі

| Параметр | Значення |
|---|---|
| Адреса маршрутизатора | `192.168.0.1/24` |
| DHCP-діапазон | `192.168.0.100-192.168.0.149` |
| SSID | `LAB12` |
| Канал | `6` |
| Захист | `WPA2 Personal`, `AES` |
