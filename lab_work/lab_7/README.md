# Lab 7 - Inter-VLAN Routing

Laboratory work on VLAN segmentation and inter-VLAN routing with a Cisco multilayer switch.

Completed tasks:

- VLAN 2 designers;
- VLAN 3 buhgalteria;
- VLAN 4 administraciya;
- VLAN 5 managers;
- VLAN 6 servers;
- access ports on SW_1 and SW_2;
- IEEE 802.1Q trunks to SW_MAIN;
- SVI gateways and `ip routing` on SW_MAIN;
- static default route through 192.168.6.201;
- ping verification between user and server VLANs.
